# План реализации интернационализации (ru / kk / en)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Сайт Седоны говорит на трёх языках — русском без префикса, казахском на `/kk/`, английском на `/en/` — с переключателем в подвале и полной разметкой hreflang.

**Architecture:** Встроенный `i18n` Astro с `prefixDefaultLocale: false`. Страницы лежат под рест-параметром `src/pages/[...locale]/`, поэтому файлов четыре, а не двенадцать. Тексты живут в трёх типизированных словарях, где русский — источник типа: пропущенный ключ в казахском или английском роняет `astro check`. Локаль компоненты спрашивают у `Astro.currentLocale`, пропы не прокидываются.

**Tech Stack:** Astro 7.1.6, TypeScript 6 (`astro/tsconfigs/strictest`), `@astrojs/sitemap` 3.7, Playwright 1.62, Yarn 1.22.22 (classic).

Спека: `docs/superpowers/specs/2026-09-18-i18n-design.md`

## Global Constraints

- **Пакеты ставятся только через Yarn.** `npm install` / `npm i` запускать нельзя — npm 7+ перезаписывает `yarn.lock`. Запускать скрипты через npm (`npm run build`, `npx eslint`) безопасно.
- **Работаем прямо в `main`.** Веток под задачу не заводим, история линейная.
- **Комментариев в `.ts`, `.astro` и `.css` не пишем.** Исключения — директивы инструментам (`eslint-disable`, `@ts-expect-error`) и конфиги тулинга. «Почему» уходит в `docs/adr/`.
- **Донор закрыт для правок.** Каталоги `../978835-sedona-18/source` и `../sedona` только читаются.
- **Числа и формулировки донора переносятся дословно.** 2000 остаётся 2000, рубль остаётся рублём. Переводится только слово-обёртка.
- **Ступени адаптива — `768px` и `1200px`**, mobile-first, `--layout-width: 1200px`.
- **Литералов времени в компонентах нет** — только токены `--duration-*` и `--ease-*`.
- **`transition-property` перечисляется всегда.** `transition-duration` без него — это `transition: all`.
- **Скрипты цепляются за `data-*`, не за классы.** Тексты состояний лежат в разметке, а не в модуле.
- **Класс, навешиваемый снаружи компонента, обязан быть глобальным.** Таких три: `.button`, `.main-style-title`, `.visually-hidden` — все в `src/styles/global.css`. Scoped-стили границу компонента не пересекают.
- **В словарях запрещён `as const`.** С ним `type Dict = typeof ru` потребует не те же ключи, а те же буквы.
- **В словарях запрещены массивы.** Только объекты с ключами: у `string[]` длина не проверяется.
- **Коммит делается на своём шаге плана и только на нём.**

- `src/i18n/index.ts` — локали, `useTranslations`, `localePaths`, `localeTag`, `ogLocale`. Единственный модуль, который знает про список языков.

- `src/components/language-switcher.astro` — переключатель. Отдельный компонент, потому что подвал и без него на 202 строки.
- `tests/i18n.spec.ts` — то, чего не видит `astro check`.
- `docs/adr/0006-i18n.md`.

### Task 1: Словарь и модуль локалей

Самая большая задача по объёму текста и самая простая по логике. Ничего ещё не подключается: на выходе три словаря одинаковой формы и `astro check`, который это доказывает.

**Files:**
- Create: `src/i18n/ru.ts`
- Create: `src/i18n/kk.ts`
- Create: `src/i18n/en.ts`
- Create: `src/i18n/index.ts`

**Interfaces:**
- Consumes: ничего.
- Produces:
  - `export type Dict = typeof ru` (из `ru.ts`)
  - `export const LOCALES: readonly ['ru', 'kk', 'en']`
  - `export type Locale = (typeof LOCALES)[number]`
  - `export const DEFAULT_LOCALE: Locale`
  - `export const isLocale: (value: string | undefined) => value is Locale`
  - `export const localeOf: (value: string | undefined) => Locale`
  - `export const localeTag: (locale: Locale) => string` — `ru-RU` / `kk-KZ` / `en-US`
  - `export const ogLocale: (locale: Locale) => string` — `ru_RU` / `kk_KZ` / `en_US`
  - `export const localePaths: () => { params: { locale: string | undefined } }[]`
  - `export const useTranslations: (value: string | undefined) => Dict`

- [ ] **Шаг 7: Написать модуль локалей**

Создать `src/i18n/index.ts`:

```ts
import type { Dict } from '@/i18n/ru'
import ru from '@/i18n/ru'
import kk from '@/i18n/kk'
import en from '@/i18n/en'

export type { Dict }

export const LOCALES = ['ru', 'kk', 'en'] as const

export type Locale = (typeof LOCALES)[number]

export const DEFAULT_LOCALE: Locale = 'ru'

const TAGS: Record<Locale, string> = {
  ru: 'ru-RU',
  kk: 'kk-KZ',
  en: 'en-US',
}

const OG_LOCALES: Record<Locale, string> = {
  ru: 'ru_RU',
  kk: 'kk_KZ',
  en: 'en_US',
}

const DICTS: Record<Locale, Dict> = { ru, kk, en }

export const isLocale = (value: string | undefined): value is Locale =>
  value !== undefined && (LOCALES as readonly string[]).includes(value)

export const localeOf = (value: string | undefined): Locale =>
  isLocale(value) ? value : DEFAULT_LOCALE

export const localeTag = (locale: Locale): string => TAGS[locale]

export const ogLocale = (locale: Locale): string => OG_LOCALES[locale]

export const localePaths = (): { params: { locale: string | undefined } }[] =>
  LOCALES.map((locale) => ({
    params: { locale: locale === DEFAULT_LOCALE ? undefined : locale },
  }))

export const useTranslations = (value: string | undefined): Dict =>
  DICTS[localeOf(value)]
```

### Task 9: Документы — ADR, глоссарий, правила проекта

Задача без тестов: проверка здесь — чтение. Но она обязательна, потому что расхождение с донором без записи в ADR по правилам проекта считается ошибкой переноса.

**Files:**
- Create: `docs/adr/0006-i18n.md`
- Modify: `CONTEXT.md`
- Modify: `CLAUDE.md`

- [ ] **Шаг 1: Написать ADR**

Создать `docs/adr/0006-i18n.md` в том же стиле, что `0001`–`0005`: что решено, почему, чем пришлось заплатить. Разобрать пять решений:

1. **Три языка при русскоязычном доноре.** Донор переключателя не имел; это первое расхождение такого масштаба. Русский при этом не тронут ни в текстах, ни в адресах.
2. **Русский без префикса.** `prefixDefaultLocale: false`. Текущие адреса не ломаются, `canonical` и sitemap уже на них настроены; альтернатива с `/ru/` потребовала бы редиректа meta-refresh на статике.
3. **Страницы под рест-параметром.** `src/pages/[...locale]/` — четыре файла вместо двенадцати копий. Записать проверенное поведение: у spread-части берётся `params[name] ?? ''`, пустой сегмент отбрасывается, пустой путь становится `/` (`core/routing/generator.js`).
4. **Переключатель в подвале, а не в шапке.** На десктопе донорская шапка занята впритык: четыре пункта по 20% плюс 240px под логотип — ровно 1200px. Пятый пункт ломает `nth-child`, которыми донор раздвигал список под центрированный логотип.
5. **Цены не пересчитываются.** Правило «числа донора — числа, а не понятия» сильнее удобства: курса у проекта нет, а выдуманный курс — выдуманные данные. Переводится только слово-обёртка.

Отдельным разделом — два принятых следствия: английская версия целиком капсом, потому что `text-transform: uppercase` стоит на `body`; и ширины абзацев подогнаны под русские строки, поэтому в казахском текст ломается иначе.

И раздел про устройство словаря: почему `type Dict = typeof ru` без `as const`, почему объекты вместо массивов.

- [ ] **Шаг 2: Дописать соответствия терминов в `CONTEXT.md`**

К каждому термину в разделе «Язык» добавить казахское и английское соответствие — так, чтобы один термин не переводили тремя разными словами в трёх местах:

- **Седона** — kk `Седона`, en `Sedona`.
- **Гостиница** — kk `қонақүй`, en `hotel`. Двойное чтение сохраняется: во множественном числе и в названии раздела это каталог, в списке типов жилья — категория.
- **Инфраструктура** — kk `инфрақұрылым`, en `facilities`. Английское слово выбрано под тип в коде — `HotelFacility`, — а не буквальным переводом «infrastructure»: по-английски так фильтр не называют.
- **Отзыв** — kk `пікір`, en `review`.
- **Достопримечательность** — kk `көрікті жер`, en `attraction`. Русское «аттракцион» глоссарий запрещает, английское `attraction` при этом уместно: это разные слова, а не калька.
- **Автор фото** — kk `фото авторы`, en `photo by`.
