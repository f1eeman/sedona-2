# Седона

Сайт вымышленного туристического бюро города Седона: четыре страницы, статическая
сборка на Astro, вёрстка mobile-first.

Проект — перенос готовой учебной вёрстки на Astro. Источники лежат рядом:
`../978835-sedona-18` (адаптивная вёрстка на Sass и Gulp) и `../sedona` (ранняя
desktop-only версия). Разбор переноса — `docs/adr/0001-port-from-html-layout.md`.

## Страницы

| Адрес      | Что на ней                                                     |
| ---------- | -------------------------------------------------------------- |
| `/`        | промо, пять причин приехать, призыв и карта                    |
| `/photo/`  | галерея из четырёх фото с лайками и рабочий видеоплеер         |
| `/form/`   | форма отзыва с валидацией и двумя модальными окнами            |
| `/hotels/` | подбор гостиниц: фильтр, сортировка и каталог — всё на клиенте |

Страницы `/hotels/` в донорской вёрстке не было — только ссылка на неё в меню.
Она собрана заново по ранней версии проекта; решения — в
`docs/adr/0002-hotels-page.md`.

## Что внутри

| Слой       | Что именно                                                      |
| ---------- | --------------------------------------------------------------- |
| Тулинг     | ESLint 10, Stylelint, Prettier, husky + lint-staged, Playwright |
| Модули     | `menu.ts`, `review-form.ts`, `hotels.ts`, `likes.ts`            |
| Компоненты | шапка, подвал, баннер, спрайт, секции страниц                   |
| Стили      | `reset.css`, токены, глобальные `.button` и `.main-style-title` |
| Шрифт      | PT Sans 400/700, локально через `astro:assets`                  |
| Тесты      | навигация, мобильное меню, форма отзыва, каталог гостиниц       |

## Запуск

```
yarn install
yarn dev
```

| Команда             | Что делает                                  |
| ------------------- | ------------------------------------------- |
| `yarn build`        | `astro check` и статическая сборка в `dist` |
| `yarn preview`      | просмотр собранного                         |
| `yarn lint`         | ESLint                                      |
| `yarn lint:styles`  | Stylelint                                   |
| `yarn format`       | Prettier                                    |
| `yarn test:browser` | браузерные тесты Playwright                 |

Движение разобрано в `docs/adr/0004-motion.md`. Приёмочные снимки снимаются спеком
со скроллом (`screenshots.config.ts`), а не командой — почему, написано в
`docs/tests.md`.

Тесты поднимают собственный просмотр сборки на порту 4331. Порт занят соседним
проектом — задайте свой: `PLAYWRIGHT_PORT=4341 yarn test:browser`.

## Перед боевой выкладкой

Домен в `astro.config.mjs` и `public/robots.txt` — заглушка `https://example.invalid`.
Форма отзыва ничего не отправляет: валидная отправка показывает подтверждение и
очищает поля. Подробнее — `docs/deploy.md`.
